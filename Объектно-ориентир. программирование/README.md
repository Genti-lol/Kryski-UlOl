# Whack-a-Rat — ООП-версия

## Описание
Текстовая игра "Ударь крысу" (Whack-a-Rat), переписанная с процедурного кода на ООП.

## Установка
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск
```bash
python main.py
```

## Тесты
```bash
pytest -v
```

## Архитектура
- `Game` — управление игровым циклом, счётом, сложностью.
- `Player` — жизни, счёт, удар молотком.
- `Rat` — состояние крысы, видимость, очки.
- `GameField` — игровое поле, лунки, спавн крыс.
- `Hole` — отдельная лунка с координатами.
- `UI` — абстракция ввода/вывода (подменяется в тестах).
