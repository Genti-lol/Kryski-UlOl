Whack-A-Rat 

Участники: Красильщикова Юлия 332 группа и Гусева Ольга 333 группа

Описание проекта:

Жанр игры: классическая аркада на реакцию

Визуальный стиль: 
Игрок видит перед собой игровой автомат, внутри которого расположено игровое поле с норами разного количества, в зависимости от сложности уровня. Из норок будут вылезать крысы. 
Удар наносится молотом (при клике мышкой молот опускается и бьет по голове крысы) 

Цель: «Смогу ли я сегодня побить свой рекорд?»

Сценарий: Игрок видит перед собой 3D-игровой автомат и играет в старую популярную игру “Whac-A-Mole”

Интерфейс меню:
Табло рекорда - показывает лучший результат игрока за всё время.
Кнопка “СТАРТ” - запускает раунд. (старт: нажатие кнопки запускает таймер, и из люков начинают вылезать крысы)
Кнопка “ПАУЗА” - ставит игру на паузу 
Кнопка, при включение которой игра начинается сначала 
Кнопка включения и выключения звука музыки 

Система Рекордов: Основные принципы: 
Цель: набрать как можно больше очков.
Рекорд - это максимальное количество очков за одну игру.
Рекорд сохраняется между сессиями .

Как игра становится сложнее: 
Чем больше ты играешь, тем сложнее становится его побить. Это создает естественный вызов. У игрока будет в запасе три жизни, которые расходуются, когда не попадает по крысе. 

"Whack-A-Rat" - это чистая аркада на реакцию, где единственный соперник - это твой собственный рекорд. Чем дольше играешь, тем быстрее появляются и исчезают крысы. Игра не дает тебе расслабиться - она постоянно подстраивается под твой уровень, заставляя становиться быстрее с каждой новой попыткой.
